# ViP tattoo school — курс для тату-майстрів

Репозиторій містить фінальні, затверджені тексти навчального курсу «ViP tattoo school» (автор — Вікторія Поникарова), що публікується у приватній Telegram-групі для тату-майстрів.

## Структура

Курс складається з 15 блоків, кожен — окремий файл `blocks/BLOK_N_FINAL.md`:

| № | Блок |
|---|------|
| 1 | VIP tattoo school (вступ) |
| 2 | AI-assistant |
| 3 | Безопасность |
| 4 | Материалы |
| 5 | Организация + Рабочее место |
| 6 | Практика |
| 7 | Работа с кожей |
| 8 | Трафареты |
| 9 | Pro Stories |
| 10 | 30-дневный практикум |
| 11 | Стили |
| 12 | Работа с клиентом |
| 13 | Реклама Tattoo (ZOOM) |
| 14 | Zoom - Tattoo |
| 15 | Tattoo - Certificate (диплом) |

Кожен файл-блок має однакову структуру:
- заголовок і `## Логіка структури` — короткий опис послідовності постів усередині блоку;
- `⚠️ Технічні примітки` — контекст для редактора (не публікується в Telegram);
- нумеровані розділи `## N. Назва`, де основний текст поста обгорнутий у блок ```code``` — саме цей текст публікується в Telegram без змін;
- завершальний розділ «Навігатор» з посиланнями на всі інші 14 блоків.

## `blocks/templates/`

Завантажувані матеріали, на які посилаються блоки:
- `grafik_zapisi_klientov_shablon.xlsx` — кольоровий шаблон таблиці «График записи клиентов» на 12 місяців (використовується в Блоці 12).
- `diplom_shablon.pdf` — візуальний макет іменного диплома (використовується в Блоці 15).

## `blocks/NAVIGATOR.md`

Довідковий шаблон і правила формування розділу «Навігатор», що додається в кінці кожного блоку.
